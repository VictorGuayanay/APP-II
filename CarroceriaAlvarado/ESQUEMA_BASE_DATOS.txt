🔗 RELACIONES ENTRE TABLAS
═════════════════════════════════════════════════════════════════════════════

Usuarios ─────┐
              ├──→ Rol_Usuario ─────┐
Rol ──────────────────────────────→─→ Rol_Usuario

Flujo:
1. Usuario intenta login
2. Sistema busca en Usuarios por username
3. Si existe, busca su rol en Rol_Usuario mediante id_usuario
4. Obtiene el nombre del rol desde tabla Rol usando id_rol
5. Si no tiene rol asignado, se asigna 'Empleado' por defecto

═════════════════════════════════════════════════════════════════════════════
✅ QUERY SQL RECOMENDADO PARA LOGIN
═════════════════════════════════════════════════════════════════════════════

SELECT 
    u.id_usuario, 
    u.email, 
    u.password_hash, 
    COALESCE(r.rol, 'Empleado') AS rol,  -- Si no tiene rol, 'Empleado'
    u.estado, 
    u.intentos_fallidos, 
    u.bloqueado 
FROM Usuarios u 
LEFT JOIN Rol_Usuario ru ON u.id_usuario = ru.id_usuario 
LEFT JOIN Rol r ON ru.id_rol = r.id_rol 
WHERE u.username = ?
